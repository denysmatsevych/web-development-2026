# ЛР-15. Теоретичні запитання

Запитання для підготовки до залікового заняття за темами лабораторних робіт
№1–13. Вони перевіряють розуміння того, як працюють HTML, CSS, JavaScript,
TypeScript і браузер, а не виконання конкретної роботи: на кожне можна
відповісти, не відкриваючи власного коду, звіту чи експериментів. Теми ЛР-7
(Проміжний контроль №1) входять у групи 2–5.

У кожній групі запитання впорядковано від простіших до складніших:

- **Базовий рівень** — означення та призначення.
- **Середній рівень** — порівняння, пояснення поведінки, вибір між підходами.
- **Поглиблений рівень** — механізми, межові випадки, обґрунтування рішень.

Нумерація наскрізна, тож запитання можна назвати лише номером.

## 1. Середовище розробки, Git, публікація та AI-агенти (ЛР-1)

### Базовий рівень

1. Яку роль у вебзастосунку виконують HTML, CSS і JavaScript? Що додає
   TypeScript і як його код потрапляє в браузер?
2. Хто розробляє стандарти HTML, CSS і JavaScript? Чим специфікація
   відрізняється від довідника на зразок MDN?
3. Яку задачу розв'язує formatter (Prettier), а яку — linter (ESLint)?
   Наведіть проблему, яку знайде лише linter.
4. Чим Git відрізняється від GitHub? Що роблять `commit` і `push`?
5. Що таке статичний сайт? Чому для його публікації достатньо хостингу на
   зразок GitHub Pages?

### Середній рівень

6. Чому налаштування formatter і linter зберігають у конфігураційних файлах
   проєкту, а не лише в налаштуваннях IDE?
7. Що таке гілка і pull request? Навіщо вносити зміни через гілку, а не
   напряму в `main`?
8. Що запускає новий деплой на Vercel, коли проєкт підключено до
   Git-репозиторію? Що таке preview deployment?
9. Чим чат-асистент відрізняється від coding agent? Які нові ризики
   з'являються, коли агент сам змінює файли й запускає команди?
10. Чим разовий промпт відрізняється від постійних правил проєкту
    (`AGENTS.md`, rules) і від skill? Коли доречний кожен із них?
11. Які дані не можна передавати AI-інструментам? Що означає академічна
    доброчесність, коли частину коду написав AI?

### Поглиблений рівень

12. З чого складається якісний промпт для coding agent? Що таке intent
    context і state context? Чому без критеріїв готовності агент «вгадує»
    результат?
13. Що треба перевірити, перш ніж прийняти зміни AI-агента? Чому зміна, яка
    «працює» на екрані, ще не є перевіреною?
14. Чому сайт проєкту на GitHub Pages відкривається за адресою
    `https://<user>.github.io/<repository>/`? Що станеться з посиланням
    `href="/styles.css"` на такому сайті і як цього уникнути?

### Поглиблений рівень
