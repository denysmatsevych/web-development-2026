## Компетентності та результати навчання

**Загальні:** ЗК2. Здатність застосовувати знання у практичних ситуаціях.

**Спеціальні:**

- **СК3.** Здатність до логічного мислення, побудови логічних висновків, використання формальних мов і моделей алгоритмічних обчислень, проєктування, розроблення й аналізу алгоритмів, оцінювання їх ефективності та складності, розв’язності та нерозв’язності алгоритмічних проблем для адекватного моделювання предметних областей і створення програмних та інформаційних систем.
- **СК8.** Здатність проєктувати та розробляти програмне забезпечення із застосуванням різних парадигм програмування: узагальненого, об’єктно-орієнтованого, функціонального, логічного, з відповідними моделями, методами й алгоритмами обчислень, структурами даних і механізмами управління.
- **СК18.** Здатність проектувати та розробляти інтерактивні інтерфейси на REACT.

**Результати навчання.** У результаті вивчення навчальної дисципліни студенти зможуть:

1. Розуміти принципи компонентної архітектури та застосовувати їх для розробки вебзастосунків за допомогою бібліотеки React.
2. Створювати інтерактивні та ефективні користувацькі інтерфейси, використовуючи React та JSX.
3. Використовувати хуки (useState, useEffect та інші) для управління станом компонентів та взаємодії із зовнішніми ресурсами.
4. Застосовувати Context API, useReducer або інші інструменти для управління станом у складних застосунках.
5. Реалізовувати маршрутизацію в React-застосунках за допомогою бібліотеки React Router.
6. Інтегрувати сторонні API у застосунки за допомогою Axios або Fetch для обміну даними з бекендом.
7. Застосовувати методи оптимізації продуктивності React-застосунків та дотримуватися найкращих практик написання коду.
8. Створювати та розгортати повноцінні вебзастосунки, використовуючи сучасні інструменти фронтенд-розробки.
9. Створювати доступні (a11y) інтерфейси та форми з валідацією даних (React Hook Form, Zod) відповідно до рекомендацій WAI-ARIA.
10. Тестувати React-компоненти за допомогою Vitest, React Testing Library та axe.
11. Типізувати React-застосунки засобами TypeScript і створювати застосунки з рендерингом на стороні сервера (Next.js).

**Програмні результати навчання (ОПП «Комп’ютерні науки»):**

- **ПРН9.** Розробляти програмні моделі предметних середовищ, вибирати парадигму програмування з позицій зручності та якості застосування для реалізації методів та алгоритмів розв’язання задач в галузі комп’ютерних наук.
- **ПРН10.** Використовувати інструментальні засоби розробки клієнт-серверних застосувань, проектувати концептуальні, логічні та фізичні моделі баз даних, розробляти та оптимізувати запити до них, створювати розподілені бази даних, сховища та вітрини даних, бази знань, у тому числі на хмарних сервісах, із застосуванням мов веб-програмування.
- **ПР11.** Володіти навичками управління життєвим циклом програмного забезпечення, продуктів і сервісів інформаційних технологій відповідно до вимог і обмежень замовника, вміти розробляти проектну документацію (техніко-економічне обґрунтування, технічне завдання, бізнес-план, угоду, договір, контракт).
- **ПР18.** Використовувати сучасні фреймворки на основі JavaScript для розробки серверних та клієнтських застосунків.

## Теми презентацій

A presentation is defended at the lecture whose topic it extends (the rules
are under the grading table below). Each topic goes beyond the lecture rather
than retelling it, and each needs working code: the programme grades
«аналітичні дослідження … із демонстрацією прикладів коду». Topic numbers read
П‹lecture›.‹n›; the reading for each lecture is in its row of the structure
table.

Each lecture has 15 topics, 120 in all. With 40+ students defending at least
two presentations each, the course needs 80–90 or more. If each topic goes to
one student, 120 covers two per student with room to choose, and students
aiming for three or four can take what is left.

| № | Тема презентації | Що дослідити й показати в коді |
| --- | --- | --- |
| **Лекція 1** | **Вступ до екосистеми React 19: Virtual DOM, JSX, семантика й доступність, Vite** | |
| П1.1 | Virtual DOM і reconciliation: як React вирішує, що змінити в DOM | Алгоритм порівняння дерев, роль `key`. Демо: список із `key={index}` губить стан полів після видалення елемента; виправлення стабільним `id`. |
| П1.2 | JSX без магії: у що компілюється JSX | `react/jsx-runtime`, відмінності від HTML (`className`, `htmlFor`, вирази, фрагменти). Демо: той самий компонент у JSX і через виклики `jsx()`; результат компіляції у Vite. |
| П1.3 | Семантична розмітка в React-компонентах | Фрагменти замість зайвих `div`, landmarks, ієрархія заголовків у компонентах, які перевикористовуються. Демо: «div soup» і семантична версія у вкладці Accessibility в DevTools. |
| П1.4 | Доступність у JSX: атрибути, фокус, лінтинг | `alt`, `label` і `htmlFor`, `aria-*`, керування фокусом через `ref`, `eslint-plugin-jsx-a11y`. Демо: лінтер знаходить помилки в компоненті, виправлення. |
