## 1. Individual assignment topic

Develop a modern, responsive, and accessible web application using HTML, CSS,
JavaScript/TypeScript, and a REST API.

## 2. Goal

Develop, test, and publish your own web application, demonstrating practical
proficiency with the discipline's core technologies: HTML5, CSS, JavaScript,
TypeScript, REST APIs, and modern frontend development tools.

## 3. Core requirements

Meet the following requirements:

- choose a subject area independently and agree on it with your instructor;
- create a semantic HTML5 structure;
- implement modern CSS styling and responsive design;
- meet basic web accessibility requirements in line with WCAG 2.2;
- add interactivity with JavaScript;
- integrate at least one REST API;
- implement loading and error states;
- use TypeScript to add types to part of your application;
- use a modular project structure and Vite/NPM;
- debug, test, and review your code;
- publish your completed web application online;
- provide a Git repository, README, and materials for your defense.

### Web application format

Build a web application with a simple structure in one of these formats:

- a landing page with interactive elements and data from an API; or
- a simple MPA with 2–3 pages, for example: home → catalog → details.

**You are not required to implement:**

- user authentication or registration;
- your own backend;
- a database;
- a complex administration system;
- full CRUD functionality;
- complex business logic.

The main focus is frontend development, working with APIs, code quality,
accessibility, and responsive design.

### Topic selection recommendations

Choose a topic that lets you demonstrate:

- retrieving data through a REST API;
- search, filtering, or sorting;
- displaying a list of data;
- viewing detailed information;
- at least 3 interactive scenarios;
- loading and error states;
- a responsive and accessible interface.

## 6. Deliverables

You must submit:

1. A Git repository with the source code.
2. A published web application with an accessible URL.
3. A README describing the project's purpose, technologies, API, setup
   instructions, and main features, plus a brief technical report describing
   the solutions you implemented.
4. A defense of your work, including a demonstration of the application and an
   explanation of your code.

## 7. Minimum requirements for the web application

- include a semantic HTML5 structure;
- have a responsive interface;
- use CSS variables and modern CSS layout techniques;
- include at least 3 interactive scenarios;
- retrieve and display data from a REST API;
- handle loading and error states;
- include TypeScript code;
- have basic tests;
- pass a basic accessibility check;
- be published online.

## 8. Defense

During your defense:

- demonstrate your web application;
- show your Git repository;
- explain your project structure;
- explain key parts of your HTML, CSS, and JavaScript/TypeScript;
- demonstrate how the REST API works;
- demonstrate debugging and testing;
- justify your main technical decisions;
- answer questions about your own code.
