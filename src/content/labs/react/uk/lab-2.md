## 1. Мета роботи

Написати власноруч чотири React-компоненти, передати їм дані через пропси й
побачити застосунок як два дерева: дерево рендерингу й дерево залежностей
модулів.

**Очікуваний результат:** у теці `lab-2/` репозиторію `react-labs` —
сторінка «Команда проєкту» з компонентів `Header`, `Avatar`, `Profile` і
`Card`; у `lab-2/README.md` — обидва дерева; застосунок відкривається на
Vercel.

Компоненти сторінки:

```text
App
├── Header
├── Card «Тімлід»
│   └── Avatar           size={120}
└── Card «Команда»
    └── Profile × 4
        └── Avatar       size не передано
```

## 2. Корисні посилання

Теоретичної частини в цій роботі немає: усе потрібне є в документації React
українською. Перед заняттям прочитайте сторінки 4 і 6, решту відкривайте,
коли до них відсилає завдання.

1. [Ваш перший компонент](https://uk.react.dev/learn/your-first-component) —
   компонент як функція, що повертає розмітку; чому його назва починається з
   великої літери.
2. [Імпорт та експорт компонентів](https://uk.react.dev/learn/importing-and-exporting-components) —
   один компонент у файлі, `export default` та `import`.
3. [JavaScript у JSX із фігурними дужками](https://uk.react.dev/learn/javascript-in-jsx-with-curly-braces) —
   `{…}` в атрибутах і в тексті; чим `"120"` відрізняється від `{120}`.
4. [Передача пропсів до компонента](https://uk.react.dev/learn/passing-props-to-a-component) —
   головна сторінка цієї роботи.
5. [Рендеринг списків](https://uk.react.dev/learn/rendering-lists) — `map` і
   `key` (§4.4).
6. [Розуміння вашого UI як дерева](https://uk.react.dev/learn/understanding-your-ui-as-a-tree) —
   дерево рендерингу й дерево залежностей модулів (§4.6).
7. [Інструменти розробника React](https://uk.react.dev/learn/react-developer-tools) —
   вкладка **⚛ Components**.

### 4.2. `Header`: рядкові пропси

Перший компонент — приклад. Перепишіть його й розберіться в кожному рядку.

1. Створіть теку `src/components/` і в ній файл `Header.jsx`:

   ```jsx
   export default function Header({ title, subtitle }) {
     return (
       <header className="header">
         <h1>{title}</h1>
         <p>{subtitle}</p>
       </header>
     )
   }
   ```

   - Компонент — функція, що повертає JSX. Назва починається з великої
     літери: так React відрізняє ваш `<Header>` від HTML-тегу `<header>`.
   - React передає всі пропси одним об'єктом — першим параметром функції.
     `{ title, subtitle }` — деструктуризація: вона дістає з цього об'єкта два
     поля.
   - `{title}` у розмітці вставляє значення пропа.
   - `export default` дає змогу імпортувати компонент в іншому файлі.

2. Замініть вміст `src/App.jsx`:

   ```jsx
   import Header from './components/Header.jsx'

   export default function App() {
     return (
       <>
         <Header title="Команда проєкту" subtitle="ЛР-2: компоненти й пропси" />
         <main>
           <p>Тут буде сторінка команди.</p>
         </main>
       </>
     )
   }
   ```

   Компонент повертає один кореневий елемент, тому `Header` і `<main>`
   загорнуто у фрагмент `<>…</>`: він групує елементи й нічого не додає в
   DOM.

**Що має вийти:** заголовок «Команда проєкту» з підзаголовком.

**Коміт:** `feat: add Header`.
**Довідка:** [Крок 2: Читайте пропси всередині дочірнього компонента](https://uk.react.dev/learn/passing-props-to-a-component#step-2-read-props-inside-the-child-component).

### 4.3. `Avatar`: об'єкт у пропсі й значення за замовчуванням

Далі код компонентів пишете самі. Створіть `src/components/Avatar.jsx`.

| Проп     | Що це                                 | За замовчуванням |
| -------- | ------------------------------------- | ---------------- |
| `person` | об'єкт учасника з `data.js`           | —                |
| `size`   | ширина й висота зображення в пікселях | `64`             |

Компонент рендерить один `<img>` з `className="avatar"` і такими
атрибутами:

| Атрибут           | Значення       |
| ----------------- | -------------- |
| `src`             | `person.photo` |
| `alt`             | `person.name`  |
| `width`, `height` | `size`         |

Значення за замовчуванням задають у деструктуризації: `{ person, size = 64 }`.

Щоб перевірити компонент, додайте в `App.jsx` два імпорти:

```jsx
import Avatar from './components/Avatar.jsx'
import { team } from './data.js'
```

і замініть рядок `<p>…</p>` усередині `<main>` двома аватарами:

```jsx
<Avatar person={team[0]} size={120} />
<Avatar person={team[1]} />
```

Число передають у фігурних дужках: `size={120}`. Запис `size="120"` передав би
рядок.

**Що має вийти:** великий аватар «ОК» і менший «АМ». Другому `size` не
передано, тож діє значення за замовчуванням.

**Коміт:** `feat: add Avatar`.
**Довідка:** [Знайомі пропси](https://uk.react.dev/learn/passing-props-to-a-component#familiar-props),
[Вказання значення за замовчуванням для пропа](https://uk.react.dev/learn/passing-props-to-a-component#specifying-a-default-value-for-a-prop).

### 4.4. `Profile` і список команди

Створіть `src/components/Profile.jsx`. Проп — `person`. Компонент рендерить
`<article className="profile">`, а в ньому по черзі:

1. `Avatar` з пропом `person` і без `size`;
2. `<h3>` з `person.name`;
3. `<p>` з `person.role`.

`Profile` використовує `Avatar`, тож імпортуйте його у `Profile.jsx`:
`import Avatar from './Avatar.jsx'` — шлях відносно теки
`src/components/`.

У `App.jsx` імпортуйте `Profile`:

```jsx
import Profile from './components/Profile.jsx'
```

і замініть другий аватар (той, що без `size`) списком команди. Перший аватар
залиште: у §4.5 він переїде в картку «Тімлід».

```jsx
{team.map((person) => (
  <Profile key={person.id} person={person} />
))}
```

`map` перетворює кожного учасника на `<Profile>`. `key` допомагає React
розрізняти елементи списку; його беруть з даних (`id`), а не з індексу масиву.

**Що має вийти:** великий аватар, під ним — чотири профілі з аватарами,
іменами й ролями.

**Коміт:** `feat: add Profile and the team list`.
**Довідка:** [Крок 1: Передайте пропси до дочірнього компонента](https://uk.react.dev/learn/passing-props-to-a-component#step-1-pass-props-to-the-child-component),
[Збереження порядку елементів списку за допомогою key](https://uk.react.dev/learn/rendering-lists#keeping-list-items-in-order-with-key).

### 4.5. `Card`: `children`

Створіть `src/components/Card.jsx`.

| Проп       | Що це                                   |
| ---------- | --------------------------------------- |
| `title`    | заголовок картки                        |
| `children` | усе, що стоїть між `<Card>` і `</Card>` |

Компонент рендерить:

```jsx
<section className="card">
  <h2>{title}</h2>
  <div className="card-content">{children}</div>
</section>
```

Тепер зберіть сторінку: остаточний `src/App.jsx` має бути таким.

```jsx
import Header from './components/Header.jsx'
import Avatar from './components/Avatar.jsx'
import Profile from './components/Profile.jsx'
import Card from './components/Card.jsx'
import { team } from './data.js'

export default function App() {
  const lead = team[0]

  return (
    <>
      <Header title="Команда проєкту" subtitle="ЛР-2: компоненти й пропси" />
      <main>
        <Card title="Тімлід">
          <Avatar person={lead} size={120} />
          <p>{lead.name}</p>
        </Card>
        <Card title="Команда">
          {team.map((person) => (
            <Profile key={person.id} person={person} />
          ))}
        </Card>
      </main>
    </>
  )
}
```

Той самий `Card` показує різний вміст: JSX, вкладений між `<Card>` і
`</Card>`, React передає в проп `children`.

**Що має вийти:** сторінка, як на знімку в §1.

**Коміт:** `feat: add Card`.
**Довідка:** [Передача JSX як children](https://uk.react.dev/learn/passing-props-to-a-component#passing-jsx-as-children).

### 4.6. Два дерева

1. Відкрийте DevTools → **⚛ Components** і розгорніть дерево. Порівняйте
   його зі схемою в §1. Біля кожного `Profile` DevTools показує його `key`.
2. Виберіть `Avatar` у картці «Тімлід», потім `Avatar` у будь-якому
   `Profile`, і порівняйте їхні **props**. Чому `size` є лише в першого,
   хоча другий теж має розмір, — запитають на захисті.
3. У того самого `Avatar` з картки «Тімлід» клацніть значення `size` у
   **props**, введіть `200` і натисніть `Enter`: аватар збільшиться без
   зміни коду. Перезавантажте сторінку — розмір знову 120.
4. Для цього ж `Avatar` знайдіть поле **rendered by**: хто його рендерить?
5. Заповніть у `lab-2/README.md` обидва дерева:
   - **дерево рендерингу** — за вкладкою ⚛ Components: усі компоненти від
     `App` до кожного `Avatar`, з усіма чотирма `Profile`;
   - **дерево залежностей модулів** — за рядками `import`: від `main.jsx` до
     кожного файлу, який імпортується прямо чи через інший файл, разом з
     `index.css` і `data.js`; пакети `react` і `react-dom` не потрібні.

   Пишіть у стилі схеми з §1: символи `├──`, `└──` і `│` можна скопіювати
   звідти, а можна позначати вкладеність лише відступами.

**Коміт:** `docs: add the lab 2 trees`.
**Довідка:** [Дерево рендерингу](https://uk.react.dev/learn/understanding-your-ui-as-a-tree#the-render-tree),
[Дерево залежностей модуля](https://uk.react.dev/learn/understanding-your-ui-as-a-tree#the-module-dependency-tree).

**Питання для підготовки:**

_Компоненти_

- Що таке компонент у React? Чим він відрізняється від звичайної функції
