## 1. Загальна ідея

Необхідно зверстати одну секцію сторінки з заголовком, коротким описом і трьома
тарифними картками. JavaScript для цього завдання не потрібен: основна увага
приділяється HTML та CSS. Орієнтовний вигляд секції показано вище: на широкому
екрані три картки стоять в один ряд, картка Pro візуально виділена.

**Плани**

- **Basic** — $10 / month — 1 User, 5GB Storage, Basic Support — кнопка
  `Select`.
- **Pro (Active)** — $29 / month — 5 Users, 50GB Storage, Priority Support —
  кнопка `Get Started`. Картка повинна бути візуально виділена.
- **Enterprise** — $99 / month — Unlimited, 1TB Storage, 24/7 Support — кнопка
  `Contact`.

## 2. HTML-структура

Використайте семантичну структуру: секція сторінки, контейнер, заголовок секції
та три `article`-картки. Для переліку можливостей тарифу використовуйте
маркований список `<ul>`.

## 3. CSS Variables

Усі основні кольори, базові розміри шрифту та відступи винесіть у `:root`. У
подальших правилах використовуйте функцію `var(...)`, а не дублюйте значення
вручну.

```css
:root {
  --color-primary: #2563eb;
  --color-primary-hover: #1d4ed8;
  --color-surface: #ffffff;
  --color-background: #f8fafc;
  --color-text-main: #0f172a;
  --color-text-muted: #64748b;
  --color-border: #e2e8f0;
  --color-accent: #f59e0b;

  --font-family-base: 'Inter', sans-serif;
  --font-size-base: 16px;
  --font-size-h1: 2.5rem;
  --font-size-h2: 1.5rem;
  --font-size-small: 0.875rem;

  --spacing-sm: 8px;
  --spacing-md: 16px;
  --spacing-lg: 24px;
  --spacing-xl: 32px;
  --border-radius: 12px;
}
```

## 4. Обов'язкові вимоги до CSS

**Box Model.** Для всіх елементів застосуйте `box-sizing: border-box`. Картки
повинні мати `padding`, `border`, `border-radius` і контрольовану ширину.

**Inheritance.** Задайте спільний шрифт і базовий колір на рівні `body`, а не
дублюйте їх для кожного елемента.

**Specificity.** Для Pro-картки використайте модифікатор на кшталт
`.pricing-card--featured`. Уникайте надто довгих селекторів та
необґрунтованого `!important`.

**Reusable classes.** Однакові стилі кнопок повинні бути винесені у спільний
клас `.btn`, а варіанти — у модифікатори.

**DRY.** Не дублюйте однакові значення та правила для трьох карток, якщо їх
можна описати одним спільним класом.

## 5. Розташування та адаптивність

На широкому екрані три картки мають розташовуватися в один ряд. На екрані
шириною менше приблизно 768px вони повинні переходити в один стовпчик.

## 6. AI-assisted розробка

AI можна використати для отримання початкової HTML/CSS-версії. Наприклад, можна
попросити асистента створити секцію з трьома тарифними картками за цим макетом.

> **Приклад запиту.** Створи HTML та CSS для секції тарифних планів із трьома
> картками Basic, Pro та Enterprise. Використай семантичний HTML, CSS Variables,
> спільний клас кнопки та просту адаптивність.

**Після генерації студент повинен:**

- перевірити структуру HTML;
- перевірити Box Model і розміри карток;
- перевірити каскад і специфічність селекторів;
- прибрати дублювання CSS;
- винести повторювані значення у CSS Variables;
- перевірити адаптивність у браузері;
- переробити код там, де AI створив зайву або складну конструкцію.

| Структура | Заголовок, опис, 3 тарифні картки, кнопки. |

## 8. Що показати під час перевірки

- Відкрити DevTools і показати Box Model для однієї картки.
- Показати правило, яке перемогло у каскаді/специфічності, та пояснити чому.
- Показати успадковану властивість, наприклад `font-family`.
- Змінити одну CSS Variable у `:root` і продемонструвати ефект на сторінці.
- Показати спільний клас кнопки або картки та пояснити, як він зменшує
  дублювання.

> **Підсумок.** Результатом має бути проста, акуратно зверстана і адаптивна
> секція тарифів. Головне під час виконання — не кількість стилів, а розуміння
> того, як CSS формує розміри, каскад, успадкування та повторне використання.
