## 1. Загальна ідея

**JS Basics** — п'ять модулів із заглушками функцій, які обробляють дані про
телесеріали з [TVmaze](https://www.tvmaze.com): нормалізують сирі записи,
фільтрують, сортують і рахують статистику за жанрами. Ще три невеликі функції
зберігають стан у замиканні.

Функції **чисті**: отримують дані лише через параметри, повертають результат і
нічого не змінюють — ні своїх аргументів, ні змінних поза собою.

> Тести — це ця специфікація у вигляді коду: назва кожного тесту — правило, яке
> він перевіряє. Якщо тест і текст нижче здаються вам суперечливими, правий
> тест, а про суперечність повідомте викладача.

## 3. Дані

### 3.1. Запис TVmaze — вхід C1

Такий вигляд мають записи в `data/shows.json`:

```json
{
  "id": 175,
  "url": "https://www.tvmaze.com/shows/175/house-of-cards",
  "name": "House of Cards",
  "language": "English",
  "genres": ["Drama", "Thriller"],
  "status": "Ended",
  "runtime": null,
  "premiered": "2013-02-01",
  "rating": { "average": 8.2 },
  "network": null
}
```

Поля `genres`, `runtime`, `premiered`, `rating` і `network` можуть дорівнювати
`null` або бути відсутніми; `rating.average` теж може бути `null`.

### 3.2. Show — результат C1, вхід C2–C4

```js
{
  id: 175,
  name: 'House of Cards',
  year: 2013,
  rating: 8.2,
  runtime: null,
  network: null,
  genres: ['Drama', 'Thriller'],
}
```

`year`, `rating`, `runtime` — число або `null`; `network` — рядок або `null`;
`genres` — масив рядків, можливо порожній.

## 4. Функції

### C1. `normalizeShow(raw)`

Перетворює запис TVmaze (§3.1) на Show (§3.2).

1. Результат має **рівно** сім полів: `id`, `name`, `year`, `rating`,
   `runtime`, `network`, `genres`. Інших полів запису (`url`, `language` тощо)
   у ньому немає.
2. `year` — рік прем'єри **числом**: `"2013-02-01"` → `2013`. Якщо `premiered`
   дорівнює `null` або відсутнє — `null`.
3. `rating` — значення `rating.average`. Оцінка `0` — це оцінка, а не її
   відсутність. Якщо `rating.average` дорівнює `null`, а також якщо `rating`
   дорівнює `null` або відсутнє — `null`.
4. `runtime` — як у записі; якщо `null` або відсутнє — `null`.
5. `network` — значення `network.name`; якщо `network` дорівнює `null` або
   відсутнє — `null`.
6. `genres` — **новий** масив із тими самими жанрами; якщо поля немає — `[]`.
7. Запис `raw` не змінюється.

### C2. `filterShows(shows, options)`

`options` — об'єкт `{ query, genre, minRating }`. Будь-яке поле, як і сам
`options`, можна не передавати.

1. `query` — залишаються серіали, у назві яких є цей рядок. Регістр не
   враховується, пробіли на початку й у кінці `query` — теж.
2. `genre` — залишаються серіали, серед жанрів яких є саме цей (точний збіг).
3. `minRating` — залишаються серіали з оцінкою **≥** `minRating`. Серіали без
   оцінки (`rating: null`) не проходять.
4. Фільтр **не задано**, якщо поле відсутнє або дорівнює `null`; для `query` і
   `genre` — ще й порожньому рядку (для `query` — і рядку з самих пробілів);
   для `minRating` — ще й `0`. Не заданий фільтр нічого не відкидає: при
   `minRating: 0` серіали без оцінки залишаються.
5. Задані фільтри поєднуються через «і».
6. Повертає **новий** масив у вихідному порядку — навіть якщо жоден фільтр не
   задано. Вхідний масив і його об'єкти не змінюються.

### C3. `sortShows(shows, key, direction = 'asc')`

1. `key` — `'name'`, `'year'` або `'rating'`; `direction` — `'asc'` (за
   замовчуванням) або `'desc'`.
2. `year` і `rating` порівнюються як **числа**.
3. `name` порівнюється через `localeCompare`: регістр першої літери не визначає
   порядку (`black-ish` іде перед `Lost`).
4. Записи, у яких значення `key` дорівнює `null`, завжди **в кінці** — і при
   `'asc'`, і при `'desc'`.
5. Записи з однаковим значенням `key` зберігають вихідний порядок відносно
   одне одного — в обох напрямках.
6. Повертає **новий** масив; вхідний не змінюється.

### C4. `genreStats(shows)`

1. Повертає звичайний об'єкт: ключ — назва жанру, значення —
   `{ count, averageRating }`. Ключ є для кожного жанру, який має хоча б один
   серіал.
2. `count` — скільки серіалів мають цей жанр, з оцінкою чи без.
3. `averageRating` — середня оцінка серіалів цього жанру, **у яких є оцінка**:
   `null` у середнє не входить, `0` — входить. Значення округлене до одного
   знака після коми і є **числом**: `8.2`, а не `'8.2'`.
4. Якщо в жодного серіалу жанру немає оцінки — `averageRating: null` (не `NaN`
   і не `0`).
5. Серіали без жанрів не враховуються; порожній масив → `{}`.
6. Вхідні дані не змінюються.

```js
genreStats([
  { name: 'A', rating: 8, genres: ['Drama', 'Crime'] },
  { name: 'B', rating: null, genres: ['Drama'] },
  { name: 'C', rating: 7, genres: ['Drama'] },
]);
// { Drama: { count: 3, averageRating: 7.5 }, Crime: { count: 1, averageRating: 8 } }
```

### C5. Замикання: `createCounter`, `once`, `memoize`

**`createCounter(start = 0)`** повертає об'єкт рівно з трьома методами:

- `increment()` — збільшує значення на 1 і повертає нове;
- `reset()` — повертає значення до `start` і повертає його;
- `value()` — поточне значення.

Кожен виклик `createCounter` створює незалежний лічильник. Значення не
зберігається у властивості об'єкта, і методи працюють, навіть коли їх викликано
окремо від нього: `const { increment } = createCounter();`.

**`once(fn)`** повертає функцію, яка під час першого виклику викликає `fn` з тими
самими аргументами й повертає її результат, а під час наступних не викликає
`fn` і повертає той самий перший результат — навіть якщо це `undefined`. Кожна
обгортка незалежна від інших.

**`memoize(fn)`**, де `fn` приймає один аргумент-примітив, повертає функцію, яка
для нового значення аргументу викликає `fn` і запам'ятовує результат, а для вже
баченого повертає запам'ятований, не викликаючи `fn`. Аргументи `1` і `'1'` —
різні. Запам'ятовується будь-який результат, зокрема `0`, `false` і
`undefined`. Кожна memoize-функція має власну пам'ять.

## 5. Обмеження

- Змінюйте лише файли в `src/`. Тести, дані, `main.js` та `index.html`
  залишаються такими, як у starter-проєкті.
- Без DOM, таймерів, Promise, бібліотек і `console.log` у фінальному коді.
- Без стану на рівні модуля: усе, що функція пам'ятає між викликами, живе в
  замиканні (C5).
- Вхідні дані не змінюються. Тести їх заморожують, тож спроба зміни
  закінчиться `TypeError`.
- Код функцій пишете ви. AI-агент може пояснити поняття чи повідомлення тесту,
  але не пише функцію (§5.2 лабораторної роботи).
