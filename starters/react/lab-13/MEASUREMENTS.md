`dist/assets/….js` — один файл. Запишіть назву файлу без хеша, наприклад
`index-….js`, його розмір і розмір у gzip. Додайте рядки, якщо файлів

## Які JS-файли завантажує браузер

Значення беріть з вкладки **Network** інструментів розробника на
`npm run preview`: фільтр **JS**, позначено **Disable cache**. Поставте
«так», якщо браузер завантажив файл сторінки, коли ви відкрили адресу, і
«ні», якщо не завантажив.

| Хто відкриває | Адреса             | `BookingPage-….js` | `TicketsPage-….js` |
| ------------- | ------------------ | ------------------ | ------------------ |
| гість         | `/`                |                    |                    |
| гість         | `/account/tickets` |                    |                    |
| глядач        | `/account/tickets` |                    |                    |
