# ЛР-5. Події, контрольовані й неконтрольовані компоненти

Стартовий проєкт лабораторної роботи № 5 курсу «Розробка вебзастосунків на
React»: форма бронювання столика в кав'ярні. Інструкція:
https://denysmatsevych.github.io/web-development-2026/react/labs/lab-5/

Форма поки лише показує поля: React не обробляє жодної її події, тож
надсилає її сам браузер. Ви додасте обробники подій форми, клавіатури й миші
і для кожного значення вирішите, де воно має зберігатися: у браузері чи в
стані React. Текст підтвердження складає функція з `src/describeBooking.js`,
стилі — у `src/index.css`.

## Команди

`npm install` виконуйте в корені репозиторію `react-labs`, решту — у теці
`lab-5/`:

- `npm run dev`: dev-сервер на http://localhost:5173
- `npm run lint`: ESLint
- `npm run format:check`: перевірка форматування Prettier
- `npm run build`: production-збірка в `dist/`
