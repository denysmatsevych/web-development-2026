# ЛР-12. Вимірювання

Ці дві таблиці заповнюєте ви: першу — у §4.4 і §4.5, другу — у §4.5 і
§4.6. Як отримати значення в React DevTools, описано в інструкції, у
«Перевірці» кожного з цих завдань.

## Які компоненти рендеряться, коли бариста відмічає напій

Значення беріть із запису у вкладці **Profiler** React DevTools: «Деталі»
закрито, і під час запису ви відмічаєте один напій на картці в колонці
«Готуються». Поставте «так», якщо компонент рендерився під час цього
запису, і «ні», якщо не рендерився. Для компонента, якого ще немає на
сторінці, поставте «—».

| Компонент        | Після §4.4 | Після §4.5 |
| ---------------- | ---------- | ---------- |
| `App`            |            |            |
| `QueueProvider`  |            |            |
| `OrderComposer`  |            |            |
| `HistoryButtons` |            |            |
| `OrderDetails`   |            |            |
| `OrderBoard`     |            |            |
| `OrderColumn`    |            |            |
| `OrderCard`      |            |            |

## Які компоненти рендеряться, коли бариста відкриває «Деталі»

Значення беріть із запису у вкладці **Profiler**, як у попередній таблиці:
«Деталі» закрито, і під час запису ви натискаєте «Деталі» на одній картці.
Поставте «так», «ні» або «—», як у попередній таблиці.
