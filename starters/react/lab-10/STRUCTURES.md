# ЛР-10. Структури папок

Ці таблиці заповнюєте ви: рядок вимірювань після кожної структури
(§4.3–§4.6) і «Що обрати» наприкінці (§4.7). Рядок «Пакет» — лише якщо
виконуєте додаткове завдання §4.9. Як вимірювати, описано в інструкції,
§4.2.

## Вимірювання

«Прибрати відгуки»: скільки файлів змінено (`git diff --stat`), скільки тек
зачеплено (`git diff --dirstat=files,0`) і скільки мертвих файлів лишилося
(попередження `not-reachable-from-main` у `npm run check:deps`).

«Де живе кошик»: у скількох теках лежать шість файлів кошика: сховище,
`useCart`, `AddToCartButton`, `CartLine`, сторінка кошика й шапка з
лічильником.

| -------------------------- | --------------- | ------------ | -------------- | ---------- |

| За маршрутами (§4.4)       |                 |              |                |            |
