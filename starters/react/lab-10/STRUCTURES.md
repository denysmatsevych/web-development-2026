# ЛР-10. Структури папок

Ці таблиці заповнюєте ви: «У яких теках лежить кошик» — по рядку після
кожної структури (§4.3–§4.6), «Вибір структури» — після заняття (§4.7).
Рядок «Пакет» — лише якщо виконуєте додаткове завдання §4.9. Як рахувати
теки, описано в інструкції, §4.2.

## У яких теках лежить кошик

Кошик — це шість файлів: сховище, `useCart`, `AddToCartButton`,
`CartLine`, сторінка кошика й шапка з лічильником. «Тек» — у скількох теках
вони лежать, «Теки» — шляхи цих тек через кому.

| Структура                  | Тек | Теки |
| -------------------------- | --- | ---- |
| За типом файлів (§4.3)     |     |      |
| За маршрутами (§4.4)       |     |      |
| За функціональністю (§4.5) |     |      |
| FSD (§4.6)                 |     |      |
| Пакет (§4.9)               |     |      |

## Вибір структури

Описи проєктів, з чого обирати і як пояснити вибір — в інструкції, §4.7.
«Чому»: що в проєкті важливо і чому обрана структура для цього підходить.
