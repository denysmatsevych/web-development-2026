# ЛР-10. Структури папок

Ці таблиці заповнюєте ви: рядок вимірювань після кожної структури
(§4.3–§4.6) і «Що обрати» наприкінці (§4.7). Рядок «Пакет» — лише якщо
виконуєте додаткове завдання §4.9. Як вимірювати, описано в інструкції,
§4.2.

## Вимірювання

«Прибрати відгуки»: скільки файлів змінено (`git diff --stat`), скільки тек
зачеплено (`git diff --dirstat=files,0`) і скільки мертвих файлів лишилося
(попередження `not-reachable-from-main` у `npm run check:deps`).

«Де живе кошик»: у скількох теках лежать шість файлів кошика: сховище,
`useCart`, `AddToCartButton`, `CartLine`, сторінка кошика й шапка з
лічильником.

| Структура                  | Відгуки: файлів | Відгуки: тек | Мертвих файлів | Кошик: тек |
| -------------------------- | --------------- | ------------ | -------------- | ---------- |
| За типом файлів (§4.3)     |                 |              |                |            |
| За маршрутами (§4.4)       |                 |              |                |            |
| За функціональністю (§4.5) |                 |              |                |            |
| FSD (§4.6)                 |                 |              |                |            |
| Пакет (§4.9)               | —               | —            | —              |            |

## Що обрати

Для кожного проєкту — одна з п'яти структур (або суміш, яку ви назвете) і
одне речення, яке спирається на число з таблиці вище або на правило
структури.

1. Лендінг кав'ярні: одна сторінка, вісім компонентів, один розробник;
   зроблено за тиждень і майже не змінюється.
2. Блог і документація на Next.js: 40 сторінок зі своєю розміткою, спільні
   лише шапка й підвал.
3. Адмінка для бариста: 15 екранів (замовлення, склад, зміни) зі своїми
   таблицями й формами; спільні лише кнопки й таблиця.
4. Інтернет-магазин кави: каталог, кошик, оформлення, акаунт; три команди;
   розвивається роками; кошик і картка товару є на багатьох сторінках.
5. Три застосунки мережі кав'ярень (сайт, кіоск самообслуговування,
   адмінка) в одному репозиторії зі спільною дизайн-системою й кошиком.
6. Прототип за 24 години на хакатоні.
