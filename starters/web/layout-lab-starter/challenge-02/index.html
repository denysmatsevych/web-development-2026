Завдання · Challenge 2. Grid: adaptive card layout

← Усі challenges

  • картки мають мінімальну ширину 220px;
  • кількість колонок залежить від доступного простору;
  • між картками однаковий gap;
  • немає горизонтального overflow;
  • без окремих Media Queries для 2, 3 та 4 колонок.

Використати: repeat(), minmax(), auto-fit.

Експеримент: порівняйте repeat(auto-fit, minmax(220px, 1fr)) і repeat(auto-fill, minmax(220px, 1fr)) та поясніть різницю за результатом. Різницю видно, коли в рядок поміщається більше колонок, ніж є карток: розширте viewport або тимчасово приберіть кілька карток.
