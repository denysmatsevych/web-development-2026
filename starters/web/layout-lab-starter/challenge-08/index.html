style.css містить навмисно закладені помилки. На вузькому viewport сторінка має horizontal scroll, обрізаний hero heading, картки виходять за межі контейнера, sidebar займає непропорційно багато місця.

  1. Відкрийте DevTools і визначте елемент, який створює overflow.
  2. Перевірте його Box Model, computed width, min-width, max-width та Grid/Flexbox overlay.
  3. Знайдіть CSS rule, яка створює проблему, і визначте першопричину.
  4. Внесіть мінімальну зміну та повторно перевірте layout.
