AI-агент тут виступає у двох ролях: спочатку генерує рішення, потім перевіряє його як reviewer. Між цими етапами ви перевіряєте код самостійно.

Етап 1. Генерація. Отримайте від AI-агента CSS-рішення для такого завдання:

Create a responsive dashboard with a header, sidebar, main content area and a grid of cards. It should work on desktop, tablet and mobile.

Покладіть відповідь AI без змін у challenge-09/original/, а виправлену версію — у challenge-09/final/, щоб наприкінці порівняти початковий і фінальний CSS.

Етап 2. Власна перевірка. Перевірте рішення у DevTools і самостійно знайдіть щонайменше 3 потенційні проблеми або зайві рішення. Зверніть увагу на надмірну кількість Media Queries, фіксовані ширини, min-width, overflow, дублювання CSS, неправильне використання Flexbox/Grid, можливість використати minmax()/auto-fit та Container Query.

Етап 3. AI code review.

  1. Передайте згенерований код AI-агенту з prompt-ом для code review (§7 лабораторної).
  2. Перевірте кожну рекомендацію AI за MDN/web.dev і порівняйте з власною перевіркою: що знайшов AI, а що — ви.
  3. Виправте обґрунтовані проблеми.
  4. Порівняйте початковий і фінальний CSS.
