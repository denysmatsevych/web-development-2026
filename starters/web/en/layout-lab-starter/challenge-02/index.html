Task · Challenge 2. Grid: adaptive card layout

← All challenges

  • cards have a minimum width of 220px;
  • the number of columns adapts to the available space;
  • a uniform gap between cards;
  • no horizontal overflow;
  • no separate media queries for 2, 3, or 4 columns.

Use: repeat(), minmax(), auto-fit.

Experiment: compare repeat(auto-fit, minmax(220px, 1fr)) and repeat(auto-fill, minmax(220px, 1fr)), explaining the difference based on the outcome. The difference shows when a row has room for more columns than there are cards: widen the viewport or temporarily remove a few cards.
