Combine the skills you've acquired in a single component — a Responsive Feature Section: on desktop the cards sit in a row, on mobile one below another.

Required to use:

  • CSS Grid;
  • Flexbox for at least one inner component;
  • minmax() or auto-fit;
  • clamp();
  • a container query for at least one component;
  • DevTools to verify responsive behavior.

Optional: subgrid; container query units; named containers.

Requirements (§6): no horizontal overflow, no fixed width on the main page container, no redundant breakpoints, no overflow-x: hidden to mask layout issues, and no absolute positioning as the primary layout mechanism.
