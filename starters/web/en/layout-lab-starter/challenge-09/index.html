Task · Challenge 9. AI-generated layout review

← All challenges

The AI agent here serves two roles: first it generates a solution, then it reviews it. Between these steps, you verify the code independently.

Stage 1. Generation. Get a CSS solution from an AI agent for the following task:

Create a responsive dashboard with a header, sidebar, main content area and a grid of cards. It should work on desktop, tablet and mobile.

Put the AI's answer, unchanged, in challenge-09/original/ and your fixed version in challenge-09/final/, so that at the end you can compare the initial and final CSS.

Stage 2. Self-verification. Inspect the solution in DevTools and independently find at least 3 potential problems or redundant choices. Pay attention to excessive media queries, fixed widths, min-width, overflow, duplicate CSS, incorrect usage of Flexbox/Grid, and places where minmax()/auto-fit or a container query would do the job.

Stage 3. AI code review.

  1. Pass the generated code to the AI agent with the code review prompt (§7 of the lab).
  2. Verify each AI recommendation against MDN/web.dev and compare it with your own review: what the AI found, and what you found.
  3. Fix the problems that turn out to be justified.
  4. Compare the initial and final CSS.
