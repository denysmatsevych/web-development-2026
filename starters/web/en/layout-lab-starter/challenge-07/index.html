Task · Challenge 7. Fluid typography

← All challenges

style.css uses breakpoint-based typography: a separate font-size for each breakpoint. Replace it with fluid typography using clamp(); choose the exact values yourself.

  • text does not become too small, nor excessively large;
  • it scales smoothly, without a separate breakpoint for each font size.

DevTools experiment: resize the viewport, select h1, open Computed, and record the actual font-size for at least three widths.
