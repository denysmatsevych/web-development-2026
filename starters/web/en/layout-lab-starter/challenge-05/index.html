Task · Challenge 5–6. Container query: reusable card

← All challenges

The same .product-card appears in three places: in .sidebar, in main, and in the modal-like container .modal.

Challenge 5

  1. Build the .content-layout layout (sidebar + main) and limit the width of .modal, so that you have three containers of different widths.
  2. In a narrow container the card is vertical; in a wide one, the image and the text block sit side by side.
  3. Do not use @media to change the card layout: set container-type on the .card-wrapper wrapper and use @container.
  4. Check that each card adapts regardless of the viewport: in DevTools, change the width of the container, not of the window.

Bonus: implement a named container — container: card / inline-size;.

Challenge 6 — continue in the same style.css

  1. Make the size of the .product-card__title heading depend on the container width.
  2. Research cqw, cqi, cqmin, and cqmax, comparing them with vw.
  3. Compare the same card in a wide and a narrow container without resizing the viewport. Explain why vw and cqw produce different behaviors.
