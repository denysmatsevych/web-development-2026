Task · Challenge 3. Responsive page layout: Grid + Flexbox

← All challenges

Build a complete page layout: desktop on the left, a narrow viewport on the right.

  +-------------------------------+      +-----------------+
  |            Header             |      |     Header      |
  +---------+---------------------+      +-----------------+
  | Sidebar |        Main         |      |      Main       |
  +---------+---------------------+      +-----------------+
  |            Footer             |      |     Sidebar     |
  +-------------------------------+      +-----------------+
                                         |     Footer      |
                                         +-----------------+
  • Grid — for the general page layout and sidebar + main.
  • Flexbox — for the header, the navigation, and the .actions button group.
  • Choose the breakpoint yourself or, if possible, implement the layout shift without a media query.

Do not use: float; tables for layout; absolute positioning as the primary layout mechanism; a fixed width for the entire page.
