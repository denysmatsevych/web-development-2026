Task · Challenge 1. Flexbox: responsive header

← All challenges

  1. Place the logo, navigation, and button on a single line.
  2. Ensure vertical alignment.
  3. Set the spacing between elements with gap.
  4. Allow the navigation to wrap onto a new line.
  5. Do not use position: absolute to build the layout.
  6. Check the behavior on a narrow viewport.

Bonus challenge: when space is insufficient, the navigation wraps onto the next line automatically — without a media query.

Expected result: the header remains functional across different viewport widths.
