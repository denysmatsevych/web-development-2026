Task · Challenge 4. Subgrid: aligned cards

← All challenges

The cards have headings and text of different lengths. Align the headings, body text, and “Read more” buttons at the same levels — without fixed heights.

  1. First, implement a solution without subgrid (each card is its own Grid or Flexbox) and note what lines up and what doesn't. Keep this version so you can compare it with the subgrid solution later.
  2. Replace the implementation with subgrid (see the experiment in §4.5 of the lab).
  3. Explain: what problem does subgrid solve that is more difficult to handle with an ordinary nested Grid?
