ShowFinder self-check

The check opens index.html in the frame below and works with the app as a user does: it types a query, presses Enter, clicks the cards and “Retry”. It answers the requests to TVmaze itself, with recorded API responses, a delay, an error or a dropped connection, so the real API isn't needed. The check doesn't read the app's code. The number and name of each row is a rule from the assignment.

The check has not run: it needs JavaScript.

The check takes about a minute: the debounce and 429 rules wait in real time. The page can't see the real TVmaze, a real CORS error or the Network panel: for those, there is a manual checklist in the assignment.
